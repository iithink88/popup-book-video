# story.json 字段全表

`story.json` 是本技能的唯一剧本配置文件，渲染/配乐/素材清单全部读它。示例见 `examples/陋室铭.json`。

## 顶层字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `title` | string | 是 | 视频主题名，如「陋室铭」「赤壁赋」「校园的春天」。渲染为片头大字 |
| `subtitle` | string | 否 | 片头副标题，如「唐 · 刘禹锡」。无则留空字符串 |
| `seal` | string | 否 | 右下角红色印章里的单字，默认取 title 首字 |
| `duration` | number | 否 | 总时长秒数，默认 47.0。推荐 40~60 |
| `output_name` | string | 否 | 输出 MP4 文件名，默认 `<title>_立体书.mp4` |
| `style` | object | 否 | 见下表 |
| `scenes` | array | 是 | 场景数组，推荐 6 个（3~10 均可） |

## style 字段

| 字段 | 取值 | 说明 |
|---|---|---|
| `mood` | elegant / serene / joyful / mystic / epic | 配乐情绪，决定调式与配器力度 |
| `scale` | C / D / E / F / G / A / B | 音乐调式根音，默认 D |
| `font` | simkai / simfang / simhei / msyh | 字幕字体，中文古诗文推荐 simkai（楷体） |
| `palette` | warm / night / spring | 仅作标记，写进 bg 提示词即可，渲染不读 |

## scenes[i] 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `bg` | string | 底板图提示词。**必须是俯视等距的空白地图**，且含「没有任何…只有平坦地形」「无文字无水印」 |
| `text` | array[string] | 竖排字幕。每个元素是一列，从右到左排列。列内字符从上到下 |
| `objects` | array | 物体数组，见下 |

## objects[j] 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `key` | string | 英文短名，作文件名。同场景内不可重复。如 `pine1` `house` `scholar` |
| `prompt` | string | 物体描述（中文短句）。工具会自动加绿幕风格后缀，不要自己写背景 |
| `cx` | int | 物体底部锚点 X 坐标，基于 1536 宽底板。范围 0~1536 |
| `cy` | int | 物体底部锚点 Y 坐标，基于 1024 高底板。范围 0~1024 |
| `h` | int | 物体立起后的目标高度（像素），推荐 60~500。宽高比由原图自动定 |
| `delay` | number | 出场顺序，0 最早。推荐 0.05~1.80 递增，间隔 0.3~0.4 |

## 坐标速查（1536 × 1024 底板）

```
(0,0) ──────────────────────── (1536,0)
  │   建议物体分布区：              │
  │   x: 200 ~ 1360               │
  │   y: 500 ~ 820（底部锚点）      │
  │   右上 x>1150,y<400 留给字幕    │
  │   底部 y>920 会被裁掉（水印带）  │
(0,1024) ────────────────────── (1536,1024)
```

- 字幕面板在画面右侧，占约 150px 宽、居中高度。物体尽量避开 `cx > 1150 且 cy 在中段`。
- 物体锚点是**底部中心**，即 `place_object` 用 `(cx - w/2, cy - h)` 定位。
- 前景物体（房子、大人物）`h` 取 250~340；小物件（灯笼、花、石阶）`h` 取 100~160；远景（月亮、山）`h` 取 180~240 且 `cy` 偏上。

## 最小可跑示例

```json
{
  "title": "春日",
  "subtitle": "",
  "duration": 30,
  "style": {"mood": "serene", "scale": "D", "font": "simkai"},
  "scenes": [
    {
      "bg": "俯视等距立体书底板，羊皮纸质感，摊开的书页上只有平坦草地与小径，无房屋树木人物，无文字无水印。",
      "text": ["春眠不觉晓"],
      "objects": [
        {"key": "tree", "prompt": "一棵开满花的桃树", "cx": 400, "cy": 700, "h": 300, "delay": 0.1},
        {"key": "bird", "prompt": "一只小鸟", "cx": 900, "cy": 600, "h": 150, "delay": 0.6}
      ]
    }
  ]
}
```
