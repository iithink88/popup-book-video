# 剧本创作指南：从用户输入到 story.json

本指南用于把用户给的「名称」或「一段文字描述」翻译成可渲染的立体书剧本。核心：**6 场景 × 每场景 5~6 个可独立立起的物体**，画面是一张摊开的立体书地图。

## 一、解析用户输入

| 输入类型 | 例子 | 处理方式 |
|---|---|---|
| 单一名篇/名称 | 「陋室铭」「赤壁赋」「荷塘月色」 | 用该作品的原文句子做字幕，按文意为每句配一个场景 |
| 一段描述 | 「描写春天校园，有花坛、操场、教学楼」 | 拆成 6 个递进画面（如：校门→花坛→操场→教室→树荫→黄昏），每画面提炼一句字幕 |
| 一个主题 | 「介绍诸葛亮的一生」 | 按时间线/事件拆 6 场景，每场景一句概括字幕 |
| 无明确文本 | 「做个立体书视频」 | 先询问主题，不要擅自定题 |

**字幕来源优先级**：用户给了原文→用原文分句；只给主题→自己写 6 句对仗短句（每句 6~12 字）。字幕是竖排单列，太长会超出面板高度（每列最多约 14 字）。

## 二、场景设计原则（关键）

参考视频的节奏是「空底板 → 物体逐个弹出立起 → 全部立住 → 逐个倒下 → 切下一场景」。所以：

1. **每场景只放 5~6 个物体**，太多会拥挤、太少显空。
2. **场景之间有视觉递进**：如山水→水景→居所→庭院→人文→夜景，情绪从铺垫到高潮到收尾。
3. **最后一场景常用夜景/远景收尾**（`bg` 写「夜晚主题，深蓝草地」），观感完整。
4. **底板提示词必须强调空白**：固定写法——
   `俯视等距视角的立体书底板地图，手绘水彩羊皮纸质感，摊开的书页上只有平坦地形：<本场景地形元素>，没有任何<本场景物体>，空白场景底板。无文字无水印。`
   底板里绝对不能出现要立起的物体，否则物体会"重复"。

## 三、物体提示词写法

`prompt` 只写物体本身，例如「一棵苍劲的松树，翠绿针叶」。工具会自动拼上：
`，手绘水彩与纸艺立体质感，中国风卡通绘本，等距俯视45度，独立物体居中，纯绿色背景便于抠图，无地面无阴影无文字水印`

- 用**纯绿色背景**（不是透明）——图片生成工具返回 RGB 绿幕，`process_layers.py` 会色彩键抠成透明。
- 物体要**单体、居中、无地面无阴影**，否则抠图会带上一块地。
- 人物写「端坐/站立」比复杂动作更稳；远景剪影写「深蓝色剪影」。

## 四、坐标布局模板（可直接套用）

底板 1536×1024，物体底部锚点 `(cx, cy)`，高度 `h`：

```
远景/背景物：cy 400~550, h 180~260   （山、月亮、亭子）
中景主体：  cy 600~700, h 280~340   （房子、大树）
前景小物：  cy 720~820, h 100~200   （石阶、灯笼、花、人物坐像）
```

- 6 个物体横向铺开：`cx` 依次约 260 / 420 / 780 / 1080 / 1280 / 560，避免扎堆。
- 右上角 `cx>1150, cy<450` 留给字幕面板，别放主体。
- 底部 `cy>920` 的内容会被裁掉，别放东西。
- `delay` 从 0.05/0.10 开始，每次 +0.3~0.35，到 1.7 左右。物体按 delay 从小到大依次弹出，**靠后的物体盖在前面的上面**。

## 五、情绪与配乐对应

| mood | 适用主题 | 听感 |
|---|---|---|
| elegant | 古诗文、山水、人文 | 清雅古琴竹笛（默认） |
| serene | 春天、校园、宁静写景 | 柔和舒缓 |
| joyful | 喜庆、节日、丰收 | 明亮轻快 |
| mystic | 神话、夜景、玄幻 | 幽深神秘 |
| epic | 历史人物、宏大叙事 | 开阔有力 |

## 六、常见错误

| 错误 | 后果 | 修正 |
|---|---|---|
| 底板里写了树/房子 | 立起的物体与底板重复、穿帮 | 底板只写地形，物体单独写 |
| prompt 里自己写了绿幕描述 | 提示词重复、可能冲突 | prompt 只写物体，后缀工具自动加 |
| `h` 全设一样 | 画面没层次 | 远景小、主体大、前景小 |
| `delay` 不递增 / 相同 | 同时弹出，失去逐个立起的效果 | 严格递增，间隔 0.3 |
| 字幕超过 14 字一列 | 竖排溢出面板 | 拆成两列（text 数组两个元素） |
| 场景数过多（>8） | 每场景时长太短、积分消耗大 | 控制在 6 个 |
